# 放学后的小屋：六个互动角落

入口：`/#/room/play`。顶栏「活动室」与首页纸箱剧场下方都有入口。原有节奏、分支剧场、编曲、计时、手记、留言链接继续可用。

| 路由 | 完整体验 |
| --- | --- |
| `photobooth` | 四位成员、三种背景、六种贴纸；拖动、键盘、选择框、缩放、旋转、前后顺序；可撤销重置；导出 1080×1350 PNG。 |
| `decorate` | 八种原创物品、三种灯光、拖动与键盘摆放；纸箱躲藏、音箱亮灯、合照和台灯彩蛋；自动保存，导出房间照片。 |
| `walk` | 六个原创想象街角与角色短篇；收集印章、继续路线、导出手帐；可撤销重置。地图不是现实路线。 |
| `search` | 每轮随机位置与六件目标；提示、误认反馈、完成结局与新一轮；没有时间限制，刷新可继续。 |
| `concert` | 1800 元虚拟预算，设备、宣传、灯光与演出心情；三种随机事件、六种应对；结果评分、最近五场记录与 PNG 海报。 |
| `ambient` | 三种预设、四条合成环境声通道、灯光、音量、六张本机配方收藏与场景卡导出。 |

## 素材与实现

- 角色沿用 `characters.json` 中站主提供的 Q 版 PNG。房间、物品、地图、寻物和场景卡均为本站绘制的 SVG；文字是原创同人创作。
- 不增加依赖。六个组件按路由加载；PNG 导出会先将同源图片嵌入 SVG，再交给 Canvas，避免遗漏人物。
- `src/data/playroom.js` 管理内容与目录；`src/room/playroom.js` 验证本机数据、约束物品位置并计算寻物与演出结果。
- 草稿只写入 `hitori-room:*:v1` 本机键，不访问上传或留言接口。存储受限时保留当前互动并提示无法保存，图片导出仍可用。
- 氛围引擎在点击播放时才创建音频上下文，遵守全站互动音效开关与音量；隐藏页面会暂停，卸载会关闭上下文并清理所有声源、定时器。不会后台补放。
- 合成雨声、街道与人群是滤波噪声，试音是衰减三角波；不包含商业歌曲、现场录音或语音素材。

## 验证

```sh
npm test
npm run build
python tests/browser-playroom.py
```

浏览器脚本自己启动临时构建预览，不访问外部服务。使用系统 Chromium 时设置 `HITORI_CHROMIUM_EXECUTABLE=/usr/bin/chromium`；可通过 `--case photobooth` 等仅运行一组。默认截图、PNG 与 JSON 报告在 `/tmp/playroom-qa`。

覆盖六项完整流程、实际 PNG 下载与尺寸、鼠标拖动和键盘操作、刷新恢复、重置撤销、全局静音、后台与离页清理、存储被阻止，以及 1440/390/320px 布局。原有 `tests/browser-room.py` 与 `tests/browser-routing.py` 验证原功能和管理页路由。GitHub Pages 的 room-checks 已加入新增测试。
