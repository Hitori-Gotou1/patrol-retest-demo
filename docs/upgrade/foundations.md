## 应用与页面恢复

`index.html` 在入口模块执行前显示小屋加载状态。脚本加载失败或启动超时后显示清楚的重试；没有自动刷新循环。初始路由失败也可从真实 HTML 恢复。

`appRecovery.js` / `AppRecovery.vue` 捕获路由分包和页面初始化错误，保留导航并提供重新打开、明确刷新版本与活动室入口。恢复不调用 localStorage.clear、不修改作品、草稿、收藏。图库继续独立区分数据为空、加载、失败与可用旧内容。
