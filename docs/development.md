## 分阶段实现

1. **分析与工程骨架**：实际阅读参考仓库，新增 Vue/Vite/Router、配置、锁文件、组件/数据目录；基础工程构建通过。
2. **首页与导航**：保留全屏封面，新增 GSAP 分层入场、轻微视差与舞台光效；固定导航、桌面逐幕和手机自然滚动。封面由约 1.97 MB PNG 压缩到约 139 KB WebP。
3. **角色**：数据与组件分离，四套原创几何角色图形，补充罗马音与性格关键词；主题渐变、人物滑入、文字分层、键盘/触摸切换和点击回应。
4. **音乐与相册**：三首原创 Demo，完整播放器/真实音频频谱；静态与三排流动相册、暂停、过滤、收藏和触摸/键盘预览。视频本地预览保留；新增关于页。
5. **适配与验证**：生产构建、桌面/手机浏览器、深链与历史、减少动态效果、素材请求与媒体生命周期验证。整站 19 组浏览器检查通过，覆盖桌面 1440×900 / 768 与手机 390 / 320；没有脚本错误、素材 404 或横向溢出。

各阶段查看方式统一为 `npm ci` 后 `npm run dev`；本地生产预览使用 `npm run build && npm run preview`。具体文件与目录见 README。

## 2026-10-27：整幕角色主题与圆形转场

保留现有 Vue 架构与其他四幕，仅升级角色组件、角色数据、局部样式并新增 `useCharacterTransition.js`。四种精确主题色覆盖整个角色区域，头像反馈、旧内容退场、双背景层圆形扩散、人物滑入与姓名/资料分层依次进行；单次约 1.44 秒。连续选择会完成当前事务后只处理最后一个待选目标，避免多个人物层或主题错位。

半径根据整个角色区域的最远角计算，ResizeObserver 在布局改变时更新尺寸；逐帧只写 clip-path，不读取布局。角色动作、配色、图形位置与回应文案统一来自角色数据。人物微视差与轻呼吸在离屏、页面隐藏、减少动态效果或卸载时停止。

验证：生产构建与 `npm test`（桌面/手机长区域/边界圆心覆盖）通过；Chromium 11 组角色与回归检查通过。真实动画采样约 767ms 同步提交主题与人物、1439ms 结束，始终只有一个人物图层；手机 390→320px 转场中缩放仍覆盖最远角。键盘、触摸、快速选择、中途切换减少动态效果、卸载重入及相册/音乐/剧场回归正常，无脚本或资源错误。

素材限制：用户提到的四张透明 PNG 在本次检查时尚未入库，继续保留现有 SVG，未生成或下载其他人物图。当前完整展示与比例测试针对 SVG；高清 PNG 的清晰度、透明留白、视觉高度和位置需素材到位后再验收。接入说明见 `public/assets/characters/SOURCES.md`。
