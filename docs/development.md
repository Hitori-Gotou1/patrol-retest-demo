# 开发与验证记录

## 已确认的需求取舍

| 原网站与新需求差异 | 确认结果 |
| --- | --- |
| 原生 HTML/CSS/JS 与 Vue/Vite | 迁移 Vue，保留现有五幕视觉；发布改为 Actions 构建 dist |
| 收藏墙与多排无限图片墙 | 保留收藏墙，增加流动视图切换 |
| 官网立绘只有来源，未确认转载许可 | 当前版本移除，换本站原创图形占位 |
| Music/About 不在原五幕里 | 音乐并入放映室，关于另设路由，不删纸箱与视频 |
| 代表台词缺少核实来源 | 使用明确标注的原创角色印象；不编造官方台词 |

## 分阶段实现

1. **分析与工程骨架**：实际阅读参考仓库，新增 Vue/Vite/Router、配置、锁文件、组件/数据目录；基础工程构建通过。
2. **首页与导航**：保留全屏封面，新增 GSAP 分层入场、轻微视差与舞台光效；固定导航、桌面逐幕和手机自然滚动。封面由约 1.97 MB PNG 压缩到约 139 KB WebP。
3. **角色**：数据与组件分离，四套原创几何角色图形，补充罗马音与性格关键词；主题渐变、人物滑入、文字分层、键盘/触摸切换和点击回应。
4. **音乐与相册**：三首原创 Demo，完整播放器/真实音频频谱；静态与三排流动相册、暂停、过滤、收藏和触摸/键盘预览。视频本地预览保留；新增关于页。
5. **适配与验证**：生产构建、桌面/手机浏览器、深链与历史、减少动态效果、素材请求与媒体生命周期验证。整站 19 组浏览器检查通过，覆盖桌面 1440×900 / 768 与手机 390 / 320；没有脚本错误、素材 404 或横向溢出。

各阶段查看方式统一为 `npm ci` 后 `npm run dev`；本地生产预览使用 `npm run build && npm run preview`。具体文件与目录见 README。

## 当前素材边界

- 四张角色图是可替换的原创几何人物占位；不是官方立绘。
- 三首音频是原创练习片段；不提供未经确认授权的动画歌曲。
- 背景视频与公开视频尚未配置，已有静态封面/灯光及本地预览方案。
- 相册目前三张原创/AI 同人素材，动态模式会重复展示；后续可直接追加数据。
- 新版本没有真实登录、后台、用户投稿或数据库。

下一阶段优先补充合适授权的立绘、音乐、视频与更多相册素材；资料与 UI 已分离，不需要再次重构页面。

## 验证结果

- `npm run build` 成功；Vue 页面按路由拆分，构建资源使用项目子路径。
- Chromium / Playwright 整站 19 组检查通过：首次无 hash 加载直接滚动、分屏高亮、历史记录、深链、About 返回、键盘焦点。
- 四角色快速连点、方向键与手机横向滑动；原创图形均可加载。
- 相册筛选、收藏持久化、静态/流动切换、预览与触摸切图；减少动态效果默认停止图片墙。
- 真实音频播放/暂停、切歌、进度与音量；首次访问没有创建 AudioContext，离开首页后已创建的 AudioContext 全部关闭。
- 本地视频可以播放，切回音乐面板时视频暂停。
- 手机纵向内容自然展开；低高度桌面上资料或相册允许略高于视口，没有通过裁切强行塞进一屏。
- 生产预览另外验证素材子路径、原锚点兼容、About 刷新、首次滚动高亮与 320px 布局。

测试浏览器为此环境的 Chromium；没有声称完成 Safari / Firefox 实机验证。
