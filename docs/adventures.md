# 新的一页：六项互动与常驻伙伴

活动室首页 `/#/room/play` 分为新的冒险、原有六个创作角落及练习与手记。首页纸箱剧场下方展示本次新功能；原有分享链接与存档不迁移、不清空。

| 路由 | 内容 |
| --- | --- |
| `maze` | 三关手工设计的后台潜行；方向键/WASD/触摸按钮、推箱挡光、纸箱躲藏、等待恢复电量、钥匙门、关卡解锁与最少步数。巡逻随操作推进，无实时倒计时。 |
| `effects` | 六弦合成吉他；失真、延迟、卷积混响；旋钮实时变化、旁通与踏板重排；三种预设、音色 JSON 导入导出、六秒 WAV 离线渲染；保存后可在编曲台启用。 |
| `companion` | 四位可选伙伴、原创回应、社交电量/勇气、纪念物赠送、最近八条记忆、显示/收起设置；全站悬浮入口可关闭。 |
| `echo` | 六个五声音阶琴键；三种起始难度、五轮渐长旋律、输入锁定、逐音评分、慢放对照、最高准确率与刷新恢复。 |
| `escape` | 海报与票根线索、四位密码锁、保险丝道具、三路接线、可求解九灯机关、舞台结局与纪念卡 PNG；提示、可撤销重置。 |
| `duet` | 本地同屏或传递设备；五题独立选择、交接遮盖、逐项揭晓；三轮提示接力，符号序列由四个增至六个，支持重看、退回与重试。 |

## 声音与原有编曲台

`src/audio/guitarEffectsEngine.js` 使用本站确定性拨弦缓冲、波形整形、反馈延迟和原创噪声脉冲响应，不加载歌曲、录音、麦克风或外部 SDK。实时调整增益与时延，连接结构变化时清理旧声源和余音；最多十二个声部。

效果器只在用户拨弦时申请声音。编曲台勾选「使用我的吉他音色」后只替换吉他轨道，贝斯和鼓保持原有音色。全局音效开关、音量、后台暂停和离页清理均生效。离页守卫立即使延迟授权失效，组件卸载时关闭独立上下文。离线 WAV 生成不会发声，末尾淡出。

## 伙伴记忆

`src/room/activityLog.js` 记录本机活动事件：保存合影、房间照片、集齐印章、完成寻物/演出、保存氛围/音色、导出或保存编曲、完成练琴，以及本次挑战。事件仅含白名单类型、简短摘要、本机时间与回执 ID。

伙伴按回执去重，保留最近八条记忆和八十条已见回执，纪念物最多各九十九件。同步当前页面事件与其他标签页的活动日志，回应为本站原创文字，不调用对话模型。显示偏好、记忆与进度都在本机，不上传访客数据。

## 验证

```sh
npm test
npm run build
python tests/browser-adventures.py
```

脚本自行启动临时生产预览；系统 Chromium 使用 `HITORI_CHROMIUM_EXECUTABLE=/usr/bin/chromium`，可加 `--case effects` 等定向检查。默认截图、WAV、PNG 与 JSON 报告写入 `/tmp/adventures-qa`。

单元测试搜索三关全部可达解，检查推箱/光线/能量、解谜完整依赖和灯阵可解性、旋律/双人评分、伙伴白名单与去重、音色参数限制、声部上限及迟到授权。

浏览器测试走完三关、完整解谜、默契问答与三轮接力，验证 WAV 实际音频、JSON 导入不覆盖已保存音色、编曲台联动、旧合影触发伙伴记忆、显示偏好、刷新恢复、全局静音、延迟授权后切页、存储受限及 1440/390/320px 布局。原有两套活动室浏览器测试继续运行；CI 已接入本次用例。
